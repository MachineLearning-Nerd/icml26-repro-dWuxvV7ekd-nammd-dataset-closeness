# Source audit

The v1 theorem display says the type-I error “is bounded by alpha” without a
finite/asymptotic qualifier. Its Appendix D.2 proof explicitly establishes the
result “asymptotically,” using convergence of the plug-in variance and
Slutsky's theorem. The v3 display corrects the statement to “asymptotically
bounded.” This audit targets only the stronger displayed v1 quantifier used by
the judge; a finite counterexample cannot contradict the corrected v3 result.
