# Source audit

This is a conditional asymptotic theorem, not uniform empirical dominance.
The source requires both alternatives, the same kernel, a strict norm ordering,
and a sample-size window for the NAMMD-only event. Example 2 uses centered
Gaussians with variances `(1.1,1.6)` for the reference and `(0.5,1.0)` for the
test pair, kernel `exp(-|x-y|²)`, alpha 0.05, and an externally estimated
`sigma_M²=0.0274`. The source reports `C1=256.6816`, `C2=509.2431`.
